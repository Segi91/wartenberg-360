# Wartenberg 360

Kostenlose mobile Web-App (PWA) für Angersbach und Landenhausen, Gemeinde Wartenberg (Hessen).

## Funktionen
- Startseite mit Wetter (Open-Meteo), ausgewählten Gemeindemeldungen und kommenden Terminen
- Veranstaltungskalender, Suche, Filter, Favoriten und iCalendar-Export
- Abfalltermine als **unverbindliche Vorschau** und Link zum offiziellen ZAV-Abfallkalender
- Vereinsübersicht, Rathauskontakte und wichtige Rufnummern
- Dark Mode, Offline-App-Shell und lokale Favoriten ohne Konto

## Veröffentlichung auf GitHub Pages
1. **Öffentliches Repository** namens `wartenberg-360` anlegen.
2. Die Dateien direkt in das Stammverzeichnis (`/` auf Branch `main`) hochladen.
3. `Settings` → `Pages` → `Build and deployment`: **Deploy from a branch** auswählen.
4. Branch **main**, Verzeichnis **/(root)** auswählen und **Save** anklicken.
5. Nach erfolgreicher Veröffentlichung lautet die URL bei GitHub-Benutzer `Segi91` typischerweise:
   https://segi91.github.io/wartenberg-360/

Zur Installation auf Android im Chrome-Browser: Menü → Zum Startbildschirm hinzufügen / App installieren.

## Datenschutzhinweise und Datenstand
Keine Nutzeranmeldung oder Tracking. Favoriten und letzte Wetterdaten werden nur im Browser gespeichert.
Live-Wetter über die kostenlose Open-Meteo-API. Nachrichten und Veranstaltungstermine sind **redaktionell erfasste Daten mit Stand 11. Oktober 2026**, kein Live-Feed.
Die Abfalltermine sind eine Vorschau, die tatsächlichen straßenbezogenen Termine bitte stets beim Zweckverband Abfallwirtschaft Vogelsbergkreis verifizieren.
Wartenberg 360 ist ein unabhängiges Bürgerprojekt, kein offizieller Auftritt der Gemeinde Wartenberg.
